# Озвучка текста — версия 1.2

Бесплатное приложение для Windows: вставляешь текст — получаешь mp3 и субтитры .srt.
309 голосов, 74 языка. Без регистрации, ключей и подписки. Всё работает на твоём компьютере.

## Запуск

Двойной клик по **`ozvuchka.exe`** — откроется окно программы, а не вкладка браузера.
Больше ничего устанавливать не нужно: всё внутри.

- Окно можно свернуть — программа продолжит работать.
- Закроешь окно — программа выключится сама через пару минут.
- Кнопка **«Выход»** внизу окна выключает сразу.
- Кнопка **«Открыть папку»** показывает готовые файлы.

## Что нового в 1.2

- **Настоящее окно приложения** вместо вкладки браузера: без адресной строки, без вкладок, со своей иконкой.
- **Второй запуск не плодит копии**: если программа уже открыта, поднимается её окно.
- **Сам выключается**, когда закрыли окно — не остаётся висеть в процессах.
- Кнопки «Открыть папку» и «Выход».
- Готовые файлы лежат рядом с exe, в папке `output`.

## Что умеет

- **309 рабочих голосов, 74 языка** (каталог Edge — 318, но 9 голосов не синтезируют звук, они отключены после самопроверки).
- Русских голосов два: Светлана (жен.) и Дмитрий (муж.). **Многоязычные** голоса (Ava, Andrew, Brian, Emma) читают по-русски живее — попробуй их.
- Скорость от −50% до +50%, тон ±40 Гц.
- **Субтитры .srt в подарок**: вместе с mp3 сохраняется файл с точным временем по каждому слову — подставляется в CapCut, Premiere или YouTube.
- Длинный текст режется на части автоматически и склеивается в один файл (проверено: 2 875 символов → 2 мин 57 с).
- Если вставлен русский текст, список голосов сам сужается до тех, кто русский читает.

## Ограничения

- Нужен интернет: голоса синтезирует бесплатный сервис Microsoft Edge.
- Максимум 12 000 символов за раз (около 25 минут речи).
- Клонирования своего голоса по записи в этой версии нет — это планы на 1.3.
- Озвучивай только тот текст и те голоса, на которые у тебя есть право.

## Запуск из исходников

```bash
npm install
node src/server.js
```

`src/server.js` — сервер и синтез, `src/public/index.html` — интерфейс, `src/voices.json` — каталог голосов.

Сборка exe (только на Windows):

```bash
npm install
node tools/build_exe.js
```

## Если не доверяешь exe

Весь код открыт в этом репозитории, а GitHub Actions собирает exe из этих же исходников при каждом изменении — можно сверить.

## Технически

- Локальный сервер слушает только `127.0.0.1`, наружу не смотрит.
- Окно запускается в режиме приложения (Edge/Chrome `--app=`) с отдельным профилем в папке `.app-profile` — твоя история и входы не затрагиваются.
- `msedge-tts` — библиотека бесплатного синтеза Edge.
