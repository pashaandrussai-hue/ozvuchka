# Озвучка текста — версия 1.4

Бесплатное приложение для Windows: вставляешь текст — получаешь mp3 и субтитры .srt.
Плюс озвучка **твоим голосом по записи** — на русском и английском.

## Запуск

Двойной клик по **`ozvuchka.exe`** — откроется окно программы. **Консольного окна нет**, ничего устанавливать не нужно.
При старте показывается заставка с полоской загрузки. Закроешь окно — программа выключится сама.

## Что нового в 1.4

- **Исправлен язык «своего голоса»**: раньше стояла англоязычная модель и русский текст читался неправильно. Теперь многоязычная модель, выбор языка: **русский или английский** (кнопки с флагами).
- **В обычной озвучке оставлены четыре языка**: русский, английский, французский, немецкий — по кнопкам с флагами стран.
- **Зелёная палитра** интерфейса.
- **Переключатель темы**: тёмная или светлая, выбор запоминается.

## Две функции

**1. Голоса программы** — только 4 языка, без регистрации и ключей.

| Язык | Флаг | Сколько голосов |
|---|---|---|
| Русский | 🇷🇺 Россия | 2 родных + многоязычные |
| English | 🇺🇸 США | родные + многоязычные |
| Français | 🇫🇷 Франция | родные + многоязычные |
| Deutsch | 🇩🇪 Германия | родные + многоязычные |

Вместе с mp3 сохраняются **субтитры .srt** с точным временем по каждому слову.

**2. Свой голос** — клонирование по записи (движок Chatterbox Multilingual, лицензия MIT):

| Что | Как |
|---|---|
| Образец | 10–15 секунд своей речи, кнопка «Записать» или файл |
| Язык | русский или английский (кнопки с флагами) |
| Скорость | ~8 секунд работы процессора на 1 секунду речи |
| Где считается | только на этом компьютере, запись никуда не уходит |

## Установка движка (один раз, для «своего голоса»)

```bash
cd engine
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\pip install "setuptools<81"
```

При первом синтезе модель скачается автоматически (~2 ГБ). Без движка программа работает, вкладка «Свой голос» просто сообщит, что движок не установлен.

## Запуск из исходников и сборка

```bash
npm install
node src/server.js          # запуск
node tools/build_exe.js     # сборка exe (только Windows)
```

Сборка ставит иконку, реквизиты файла и переключает PE в режим GUI (`tools/patch_subsystem.js`), поэтому консоль не появляется.

## Права и лицензии

- Голоса программы — бесплатный сервис Microsoft Edge.
- Движок клонирования — Chatterbox, лицензия MIT (коммерческое использование разрешено).
- Озвучивай только тот текст и те голоса, на которые у тебя есть право. Чужой голос без согласия — претензии и бан аккаунта.
