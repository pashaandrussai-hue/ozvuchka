# Озвучка текста — v1

Бесплатная программа: вставляешь текст — получаешь mp3. Без регистрации, без ключей, без оплаты.

## Как запустить

1. Двойной клик по **`Запустить.bat`**.
2. Откроется браузер с программой (адрес `http://127.0.0.1:8731`).
3. Вставь текст, выбери голос, нажми **Озвучить**.
4. Слушай в окне или жми **Скачать mp3**. Файлы также копятся в папке `output`.

Чтобы закрыть программу — закрой чёрное окно (или Ctrl+C в нём).

## Что внутри

- **309 рабочих голосов, 74 языка** (каталог Edge — 318, но 9 голосов не синтезируют звук, они отключены после самопроверки).
- Русских голосов два: Светлана (жен.) и Дмитрий (муж.). **Многоязычные** голоса (Ava, Andrew, Brian, Emma и др.) читают по-русски живее — попробуй их для русской озвучки.
- **Субтитры .srt в подарок.** Вместе с каждым mp3 программа сохраняет субтитры с точным временем по каждому слову — их можно сразу подставить в CapCut, Premiere или загрузить на YouTube. Проверено: заголовки, время и знаки препинания на месте, строки не накладываются друг на друга.
- Скорость от −50% до +50%, тон ±40 Гц.
- Длинный текст режется на части автоматически и склеивается в один файл (проверено на 2 875 символах → 2 мин 57 с).
- Все файлы сохраняются локально: в `output/` рядом с программой.
- Если вставил русский текст, список голосов сам сужается до тех, кто русский читает. Иноязычный голос на русском тексте даёт тишину — это особенность сервиса Edge, программа теперь предупреждает заранее.

## Ограничения

- Нужен интернет: голоса синтезируются бесплатным сервисом Microsoft Edge.
- Максимум 12 000 символов за раз (это ~25 минут речи). Больше — двумя заходами.
- **Клонирование своего голоса по записи — это v2**, в этой версии его нет. Здесь только готовые голоса.
- Озвучивай только тот текст и те голоса, на которые у тебя есть право. Чужие голоса знаменитостей — это претензии и бан аккаунта, а не «фича».

## Что нужно установить

Только **Node.js** (https://nodejs.org, кнопка LTS), если его нет. Проверить: открой `Запустить.bat` — он сам скажет.

## Технически

- `server.js` — локальный сервер на 127.0.0.1:8731 (наружу не смотрит), отдаёт страницу и озвучивает текст.
- `public/index.html` — интерфейс, один файл, без интернета и CDN.
- `voices.json` — каталог голосов, снят один раз и лежит локально.
- `msedge-tts` — библиотека бесплатного синтеза Edge, лежит в `node_modules`.
- Проверка: `curl http://127.0.0.1:8731/api/health` → `{"ok":true,"voices":318}`.
