# Озвучка текста

Бесплатная программа для Windows: вставляешь текст — получаешь mp3 и субтитры .srt.
309 голосов, 74 языка, без регистрации, ключей и подписки. Файлы остаются на твоём компьютере.

## Скачать

**[ozvuchka.exe](https://github.com/pashaandrussai-hue/ozvuchka/releases/latest/download/ozvuchka.exe)** — один файл, 96 МБ, ничего устанавливать не нужно.
Windows может предупредить, что файл без цифровой подписи: «Подробнее» → «Выполнить всё равно».

Страница программы: **https://pashaandrussai-hue.github.io/ozvuchka/**

## Что внутри

- 309 рабочих голосов, 74 языка (9 голосов каталога Edge отключены после самопроверки — они отдают пустой звук).
- Субтитры .srt с таймингом по каждому слову — подставляются в CapCut, Premiere, YouTube.
- Длинный текст режется на части сам и склеивается в один файл.
- Готовые файлы падают в папку `output` рядом с программой.
- Если вставлен русский текст, список голосов сужается до тех, кто русский читает.

## Если не доверяешь exe

В релизах есть сборка с исходниками (запуск через Node.js): [releases](https://github.com/pashaandrussai-hue/ozvuchka/releases).
Весь код открыт: `server.js` — сервер и синтез, `public/index.html` — интерфейс.

## Права

Голоса предоставляет бесплатный сервис Microsoft Edge. Озвучивай только тот текст и те голоса, на которые у тебя есть право.
Программа не клонирует чужие голоса — только читает готовыми.
