# Озвучка текста — версия 1.3

Бесплатное приложение для Windows: вставляешь текст — получаешь mp3 и субтитры .srt.
Плюс вторая функция: **озвучка твоим голосом по записи** — всё считается на твоём компьютере.

## Запуск

Двойной клик по **`ozvuchka.exe`** — откроется окно программы. **Консольного окна нет**, ничего устанавливать не нужно.

- При запуске показывается заставка с полоской загрузки.
- Окно можно свернуть — программа продолжит работать.
- Закроешь окно — программа выключится сама через пару минут.
- Кнопки **«Открыть папку»** и **«Выход»**.

## Что нового в 1.3

- **Озвучка своим голосом**: записываешь 10–15 секунд, программа читает текст твоим тембром.
- **Запуск без чёрного окна консоли** — приложение ведёт себя как обычная программа Windows.
- **Заставка при старте**: без надписей, только логотип и полоска прогресса.
- Вкладки «Голоса программы» и «Свой голос».

## Две функции

**1. Голоса программы** — 309 голосов, 74 языка, без регистрации и ключей.
Русских голосов два (Светлана, Дмитрий), многоязычные (Ava, Andrew, Brian, Emma) читают русский живее.
Вместе с mp3 сохраняются **субтитры .srt** с точным временем по каждому слову.

**2. Свой голос** — клонирование по записи (движок Chatterbox, лицензия MIT):

| Что | Как |
|---|---|
| Образец | 10–15 секунд своей речи, кнопка «Записать» или файл |
| Скорость | ~8 секунд работы процессора на 1 секунду речи |
| Где считается | только на этом компьютере, запись никуда не уходит |
| Файлы | WAV 24 кГц в папке `output` |

Движок — отдельный модуль (Python + модель ~2 ГБ), ставится один раз и лежит в папке `engine` рядом с программой.

## Установка движка (один раз, для «своего голоса»)

```bash
cd engine
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\pip install "setuptools<81"
```

При первом синтезе модель скачается автоматически (~2 ГБ). Без движка программа работает, просто вкладка «Свой голос» будет недоступна.

## Запуск из исходников

```bash
npm install
node src/server.js
```

## Сборка exe (только Windows)

```bash
npm install
node tools/build_exe.js
```

Сборка сама ставит иконку, реквизиты файла и переключает PE в режим GUI (`tools/patch_subsystem.js`), поэтому консольное окно не появляется.

## Права и лицензии

- Голоса программы — бесплатный сервис Microsoft Edge.
- Движок клонирования — Chatterbox TTS, лицензия MIT (коммерческое использование разрешено).
- Озвучивай только тот текст и те голоса, на которые у тебя есть право. Чужой голос без согласия — претензии и бан аккаунта.
